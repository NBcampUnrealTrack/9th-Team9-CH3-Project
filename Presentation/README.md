# Parcel Knight HTML 프레젠테이션

15분 발표를 위한 14장짜리 정적 HTML 프레젠테이션 뼈대입니다. 별도 서버, 설치, 빌드 과정, 인터넷 연결이 필요하지 않습니다.

## 실행 방법

1. `Presentation/index.html`을 더블 클릭합니다.
2. Chrome, Edge 등 최신 브라우저에서 바로 발표할 수 있습니다.
3. 현재 슬라이드는 URL 해시(`#slide-5`)에 기록되므로 해당 주소를 다시 열면 같은 슬라이드에서 시작합니다.

## 조작 방법

- 다음 슬라이드: `→`, `Space`, `PageDown`, 화면 오른쪽 버튼
- 이전 슬라이드: `←`, `PageUp`, 화면 왼쪽 버튼
- 첫 장 / 마지막 장: `Home` / `End`
- 번호 이동: 숫자를 입력합니다. 예: `1` 다음 `4`를 빠르게 입력하면 14번 슬라이드로 이동합니다.
- 목록 이동: 왼쪽 아래 `슬라이드 목록` 버튼을 누릅니다.
- 모바일: 화면을 좌우로 스와이프합니다.
- 상단 섹션 이름을 누르면 해당 섹션의 첫 슬라이드로 이동합니다.

## 전체 화면

- 오른쪽 위 `⛶` 버튼을 누릅니다.
- 전체 화면 해제는 `Esc`를 누릅니다.
- 화면 비율이 16:9가 아니면 여백을 사용하며 슬라이드는 찌그러지지 않습니다.

## 텍스트 수정

- 모든 발표 내용은 `index.html`에 있습니다.
- `id="slide-1"`부터 `id="slide-14"`까지 원하는 슬라이드를 찾아 대괄호가 있는 짧은 문구를 교체합니다.
- 각 슬라이드 시작 부분에 용도를 설명하는 HTML 주석이 있습니다.
- `data-title`은 슬라이드 목록과 브라우저 제목에 사용되므로 제목을 바꿀 때 함께 수정합니다.
- `data-section`은 `INTRO`, `DEMO`, `PROCESS`, `TECH`, `WRAP-UP` 중 하나를 사용합니다.

## 이미지 교체

이미지는 `assets/images/`에 넣습니다. 각 placeholder 근처의 HTML 주석에 교체 위치가 표시되어 있습니다.

```html
<img
  class="media-fill cover"
  src="./assets/images/scene-01.jpg"
  alt="첫 번째 주요 게임 장면"
>
```

- 화면을 채우는 스크린샷과 대표 이미지는 `cover`를 사용합니다.
- 구조도, 코드, Blueprint처럼 전체가 보여야 하는 이미지는 `contain`을 사용합니다.
- 이미지마다 실제 내용을 설명하는 `alt` 텍스트를 작성합니다.
- placeholder에 적힌 16:9, 4:3 권장 비율을 따르면 레이아웃 변경이 적습니다.

## 영상 교체

영상은 `assets/videos/`에 넣습니다. 4번 슬라이드의 영상 placeholder를 아래처럼 교체합니다.

```html
<video class="media-fill contain" controls preload="metadata">
  <source src="./assets/videos/demo.mp4" type="video/mp4">
  브라우저가 영상을 지원하지 않습니다.
</video>
```

- 발표 전 로컬에서 처음부터 끝까지 재생되는지 확인합니다.
- 다른 PC에서 발표할 때는 `Presentation` 폴더 전체를 함께 복사합니다.
- 큰 영상은 발표용 해상도와 용량으로 미리 압축하는 것을 권장합니다.

## 슬라이드 추가 및 삭제

1. `index.html`에서 기존 `<section class="slide">…</section>` 하나를 복제하거나 삭제합니다.
2. `id="slide-15"`처럼 고유 ID를 지정합니다.
3. `data-title`과 `data-section`을 지정합니다.
4. 숫자, 목록, 전체 장수, 진행률은 `presentation.js`가 HTML의 `.slide` 요소를 읽어 자동으로 갱신합니다. JavaScript에 슬라이드 목록을 따로 추가할 필요가 없습니다.

슬라이드 순서를 바꿀 때는 `id`도 화면 순서에 맞춰 다시 정리하는 것이 좋습니다.

## PDF로 저장

1. 브라우저 인쇄 화면을 엽니다: `Ctrl+P`.
2. 대상을 `PDF로 저장`으로 선택합니다.
3. 레이아웃은 `가로`, 여백은 `없음`을 권장합니다.
4. `배경 그래픽` 옵션을 켭니다.
5. 미리보기에서 슬라이드마다 한 페이지씩 총 14페이지인지 확인합니다.

## 파일 역할

- `index.html`: 14개 슬라이드의 내용과 의미 구조
- `styles.css`: 색상, 16:9 레이아웃, 반응형·인쇄 스타일
- `presentation.js`: 키보드·버튼·숫자·목록·스와이프·전체 화면·URL 해시 동작
- `assets/images/`: 발표 이미지와 캡처
- `assets/videos/`: 시연 영상
